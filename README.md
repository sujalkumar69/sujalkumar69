## Things I've built

### 🌍 EcoTrack

**Carbon Footprint & Sustainability Management Platform**

A team project where I worked as the **sole backend developer and team lead**.

The system combines a React/Vite frontend with a Node.js/Express backend and includes authentication, sustainability tracking and Google OAuth.

**Stack:** Node.js · Express · MongoDB · React · Vite

---

### 💰 Expense Tracker

A full-stack expense management system built around more than just CRUD.

Features include:

* JWT authentication with refresh-token rotation
* group expenses and invite codes
* automatic expense splitting
* settlement summaries
* UPI QR generation
* rate limiting

**Stack:** Node.js · React · Oracle DB

---

### 📦 Vendor / PO Management System

A project focused on **Vendor and Purchase Order management**, mapped around SAP MM and Procure-to-Pay concepts.

Currently in progress.

**Stack:** Software + SAP-oriented business workflow

---

### 🔐 SecretScan CLI

A small security-focused CLI project designed to catch accidental secret exposure before code reaches a repository.

The idea is simple:

```text
write code
   ↓
git add
   ↓
SecretScan
   ↓
🚨 secret detected?
   ↓
stop the commit
```

**Focus:** developer security · `.env` leaks · pre-commit checks
